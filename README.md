# 🌿 Air Quality & Weather Analytics for a Sustainable 

## 📌 Project Overview
This project analyzes air quality and weather data across multiple cities using Power BI. It helps identify pollution trends and understand environmental conditions through interactive dashboards and visualizations.

## 🎯 Objectives
- Analyze Air Quality Index (AQI) across cities.
- Monitor PM2.5 pollution levels and trends.
- Analyze temperature, humidity, rainfall, and wind speed.
- Compare environmental conditions across cities and dates.
- Support data-driven environmental monitoring and sustainability awareness.

## 📊 Key Features
- **Air Quality Overview:** Average AQI, maximum AQI, total cities, city-wise AQI comparison, AQI categories, and PM2.5 trends.
- **Weather Analysis:** Average, minimum, and maximum temperature, humidity trends, rainfall trends, and wind speed analysis.
- **Interactive Filters:** Filter the analysis by city and date.
- **Data Visualization:** Interactive charts and KPI cards built using Power BI.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- CSV datasets
- Data Cleaning and Transformation
- Data Visualization and Analysis

## 📁 Dataset Files
- `air_quality_daily.csv` — Air quality measurements.
- `cities.csv` — City-related information.
- `weather_daily.csv` — Daily weather observations.
- `Air_Quality_Analysis.pbix` — Power BI dashboard file.

## 📈 Expected Outcomes
The dashboard helps users explore air pollution patterns, compare weather conditions, and understand environmental trends that may support sustainability-related decisions.

## 🚀 How to Use
1. Download or clone this repository.
2. Open `Air_Quality_Analysis.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the CSV file paths to match your local folder.
4. Refresh the data and explore the interactive dashboards.

## 🌍 Conclusion
This project demonstrates how data analytics and visualization can help monitor air quality and weather conditions, providing useful insights for environmental awareness and a more sustainable future.
